Student Skill Gap Analyzer — Sample Database
================================================

Files:
1. job_roles.csv — sample job roles
2. job_skills.csv — required skills, required proficiency, and importance weights
3. learning_resources.csv — example learning resources for skills

Proficiency scale:
1 = Beginner
2 = Intermediate
3 = Advanced

Importance weight:
1 = lower importance; 5 = very important

This is sample project data for demonstration, not an official or universal industry-standard database.
The project can import these CSV files into SQLite. Job requirements should be reviewed and adapted to the target companies and roles.
